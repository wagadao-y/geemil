# Spatial Hub（apps/web）

ドローン由来の屋外メッシュ、SLAM 由来の屋内点群、360°写真を施設ローカル座標（m、Z 上向き）で重ねて表示し、場所に紐づく情報への入口にする SPA です。点検記録や文書そのものは持たず、既存システムへのリンクと添付ファイルで接続します。

```sh
pnpm dev:web   # ルートで実行。ライブラリをビルドしてから Vite を起動します
pnpm check     # svelte-check
```

SvelteKit の `adapter-static`（`fallback: index.html`、SSR なし）でビルドし、`build/` を Go のサーバーから配信する想定です。

## 画面構成

| 領域         | 内容                                                                                                                                                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ヘッダー     | 施設の切り替え、横断検索（設備名・ID・場所・写真、`Ctrl+K` / `/`）、ビューの共有リンク                                                                                                                                 |
| 左パネル     | 施設構成ツリー（任意の深さ。行ごとに表示 ON/OFF、注記を葉として表示）、保存ビュー、表示レイヤー（屋外メッシュと不透明度、屋内点群、360°写真、注記）                                                                    |
| 3D ビュー    | パンくず、建屋の表示階の切り替え（選んだ階より上を切り取り）、ビューキューブと方位、ツールバー（選択・計測・注記追加・ズーム・全体表示・全画面）、ミニマップ（クリックで移動）、縮尺、建屋・エリア・写真・注記のラベル |
| 右パネル     | 選択中の注記（位置、フォーカス、最寄りの 360°写真で見る、関連システムのリンク、添付ファイル、コメント、リンクのコピー）、または選択中の場所（件数、構成、注記一覧、写真、3D データ）                                   |
| 360°写真表示 | 撮影位置から見回し、近くの写真のフィルムストリップ、方位、撮影日。写真の中にも注記と次の撮影位置を表示                                                                                                                 |

ツリーやパンくずで場所を選ぶとその範囲へ移動し、階より下を選ぶと上の階を自動で切り取ります。共有リンクにはカメラ、非表示の場所、表示階、選択中の注記、開いている写真が入ります。

キー操作：`V` 選択、`M` 計測、`N` 注記を追加、`H` 敷地全体、`[` 左パネルの開閉、`Esc` ツールの終了・選択の解除・写真から戻る。ダブルクリックでその点に寄ります。

## 構成

```text
src/lib/types.ts                 ドメインの型（場所ノード、アセット、写真、注記、保存ビュー）
src/lib/api/client.ts            UI が使う API のインターフェースとデモ実装
src/lib/api/demo-data.ts         デモ施設のシードデータ
src/lib/state/workspace.svelte.ts 開いている施設の UI 状態（runes、コンテキストで共有）
src/lib/viewer/viewer.ts         Three.js のビューアー（点群・メッシュ・ピック・視点移動・写真モード・ラベル投影）
src/lib/viewer/site-model.ts     デモ用の屋外メッシュの代用品
src/lib/components/              画面の部品
```

## デモの制約

- データは `demo-data.ts` の 1 施設だけです。追加・編集した注記と保存ビューは localStorage に保存します。
- 屋外メッシュは建屋の外形から生成した箱です。実データでは glTF / 3D Tiles を読み込みます。
- 点群は playground の `pump` を 2 か所に配置しています。ファイルは dev サーバーだけが `dev/demo-assets.ts` から将来の API と同じ URL（`/api/sites/{site}/assets/{asset}/files/{name}`、Range 対応）で配信し、ビルドには含みません。
- 360°写真の画像はないため、撮影位置からの 3D ビューで代用しています。`Panorama.imageUrl` に正距円筒画像があれば球に貼って表示します。
